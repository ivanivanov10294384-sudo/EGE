# v1.1.1 — «Релиз с APK-ассетом» (2026-11-23)

## 📌 Кратко

Исправил релизный workflow: APK не прикреплялся к релизу из-за переменной тега, невидимой из другого шага. Этот релиз проверяет цепочку целиком: описание, ассет и обновление роллинг-релиза `apk-latest`.

## ✨ Что нового

### Изменено
- Изменил шаг прикрепления APK в release-workflow: тег берётся из стандартной `GITHUB_REF_NAME` вместо переменной из предыдущего шага

### Исправлено
- Исправил прикрепление APK к релизам: шаг загрузки обращался к пустой переменной `$TAG` — ассет не прикреплялся, и релиз выходил без файла

## ⚙️ Технические детали

- Изменён только `.github/workflows/release.yml`; на приложение, API и деплой не влияет
- **BREAKING:** нет

## 🚀 Как обновить

Миграция не требуется.

## ⚠️ Известные проблемы

- Исходников Android-проекта в репозитории нет: CI проверяет и публикует готовую сборку, но не компилирует её — для сборки в CI нужно добавить исходники приложения
- Нативный автодеплой Render (GitHub App) не подключён: деплой на пуш идёт через workflow «Deploy» и секрет `RENDER_API_KEY`
