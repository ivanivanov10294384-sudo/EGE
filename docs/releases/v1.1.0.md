## ⚙️ Технические детали

- Релизный pipeline: тег `v*` → GitHub Release из `docs/releases/X.Y.Z.md` + ассет `kabinet-repetitora.apk` + перезаливка `apk-latest`
- Деплой на Render: образ собирается из `Telegram Mini App/` (контекст Dockerfile — папка приложения); APK попадает в образ из `Telegram Mini App/docs/`
- Скачивание `/apk` публичное и без авторизации: загрузчики идут по URL без заголовков
- **BREAKING:** нет

## 🚀 Как обновить

Миграция не требуется. Для автоматического деплоя на пуш задайте секрет `RENDER_API_KEY`
(Settings → Secrets and variables → Actions) либо установите Render GitHub App на репозиторий —
тогда деплой подхватывается нативно, без workflow.

## ⚠️ Известные проблемы

- Исходников Android-проекта в репозитории нет: CI проверяет и публикует готовую сборку, но не компилирует её — для сборки в CI нужно добавить исходники приложения
- Нативный автодеплой Render (GitHub App) не подключён: деплой на пуш идёт через workflow «Deploy» и секрет `RENDER_API_KEY`
