# Tutor Bot — репетитор по ЕГЭ

## Название и описание

**Tutor Bot** — Telegram-бот-репетитор по предметам ЕГЭ. Проект включает два клиентских приложения:

- **Telegram Mini App** — веб-приложение внутри Telegram (интерактивные задания, прогресс, статистика).
- **APK mobile app** — нативное Android-приложение (мобильный доступ к функциям сервиса).
